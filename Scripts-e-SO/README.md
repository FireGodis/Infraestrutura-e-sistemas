# Scripts para Linux e Windows

Eu reuni exemplos curtos de automação: resumo de log em Bash, C Shell, KornShell, Expect, Tcl e lote do Windows.

- `log_summary.sh`: conta linhas e ocorrências em um log.
- `hello.csh`, `hello.ksh`, `hello.tcl`: exemplos mínimos.
- `check_prompt.exp`: demonstra o formato de um script Expect sem conectar a hosts.
- `info.bat`: imprime informações básicas no Windows.

Revise caminhos e comandos antes de adaptar os exemplos a outros ambientes.
