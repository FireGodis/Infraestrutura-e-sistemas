# Servidores de aplicação web

Eu mantenho exemplos de referência para Apache HTTP Server, Tomcat, JBoss/WildFly e IIS. Os arquivos são modelos para estudo; caminhos, módulos e versões devem ser ajustados ao ambiente.

## Arquivos
- `apache.conf`: VirtualHost local.
- `tomcat-context.xml`: contexto da aplicação.
- `jboss-datasource.xml`: estrutura de datasource com variáveis de ambiente.
- `web.config`: configuração básica do IIS.
